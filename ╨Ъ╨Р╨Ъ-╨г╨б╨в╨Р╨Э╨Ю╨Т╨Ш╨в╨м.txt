СКЛЕЙКА — КАК УСТАНОВИТЬ КАК ПРИЛОЖЕНИЕ
========================================

Так же, как Ретушь. Можно положить в тот же аккаунт GitHub.

1. ВЫЛОЖИТЬ
   1) github.com → «+» → New repository → имя skleika → Public → Create.
   2) Ссылка «uploading an existing file» → перетащите ВСЕ файлы из этой папки
      (не саму папку) → Commit changes.
   3) Settings → Pages → Branch: main, / (root) → Save.
   4) Через 1–2 минуты: https://ВАШ-НИК.github.io/skleika/

2. УСТАНОВИТЬ
   ПК (Chrome / Edge): значок установки в адресной строке
                       или кнопка «Установить» в самой программе.
   Android (Chrome):   ⋮ → «Установить приложение».
   iPhone (Safari):    «Поделиться» → «На экран Домой».

3. ВАЖНО ЗНАТЬ
   - Обновление: если Склейка уже выложена, просто замените на GitHub файлы
     index.html и sw.js новыми (Add file → Upload files → Commit).
   - 3D: при первом добавлении 3D нужен интернет — движок скачается один раз,
     потом 3D работает и офлайн. Модели — файлы .glb (без Draco-сжатия).
   - Свои шрифты (.ttf .otf .woff) сохраняются внутри приложения.
   - Лучше всего работает в Chrome или Edge на компьютере: там экспорт сразу в MP4.
     В Firefox и Safari видео сохранится в WebM (или экспорт может не работать).
   - Экспорт идёт в реальном времени: минута ролика ≈ минута ожидания.
     Не сворачивайте окно, пока идёт сохранение.
   - Проект сохраняется сам на этом устройстве. Начать заново — Файл › Новый проект.
   - Видео с iPhone в формате HEVC (.mov) браузер может не открыть —
     тогда в настройках камеры выберите «Наиболее совместимый» (H.264).
